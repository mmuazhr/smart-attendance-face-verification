# PresenceGuard

PresenceGuard is a privacy-first modernization of a 2023 final-year project on face verification for attendance. The recovered baseline is being reconstructed and measured before the modern implementation is finalized.

> Work in progress: historical biometric data and model weights are private and excluded from this repository. See [`docs/original-baseline.md`](docs/original-baseline.md) for current evidence and limitations.
